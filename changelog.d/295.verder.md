Een kopie van een bevroren veegronde die met `variant` is gemaakt, gaat na een release verder met de fasen van de agents (`tasks`, `skip`, `check-walk`, `check-verdict`, `evaluate`, `merge` en de rest), zonder `--other-toolbox`, en meldt dan van welke versie de veegronde is. De veegronde zelf (`collect`, `contrast`, `states`, `documents`, `inventory` en de rest) weigert in een kopie met een andere versie dan die van de veegronde, ook als de kopie met nieuwere code is gemaakt; tot nu toe ging dat dan zonder melding door. `compare-variants` noemt per run de versie van de code en, voor een kopie, de run en de versie van de veegronde.
