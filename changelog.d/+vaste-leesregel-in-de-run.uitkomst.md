In een run met inlog hield de veegronde een verzoek tegen dat een vaste leesregel dekt, ook als het naar een host ging die bij de run hoort, wanneer de browser daar een cookie van de site voor had. Een sessie liet zo'n verzoek wel door. De veegronde doet nu hetzelfde: alleen een verzoek naar een host buiten de run wordt nagelopen op geheimen van de run. Wat een ingesloten speler of vragenlijst zo ophaalt, kan daardoor nu in het bewijs staan.
